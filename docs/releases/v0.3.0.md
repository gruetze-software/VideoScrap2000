# VideoScrap 2000 0.3.0

The first release of VideoScrap 2000, a desktop metadata and artwork manager for movies and TV shows.

## Features

- Separate movie and TV-show libraries, including seasons and episodes.
- Metadata from TMDB and artwork from TMDB and Fanart.tv.
- Editable titles, plot outlines, descriptions, cast, ratings, certifications, collections, and provider IDs.
- NFO and artwork files saved alongside the videos, with backups of replaced files.
- TV artwork selection for the show or a specific season, including poster, fanart, banner, logo, clear art, landscape, and character art where available.
- Episode stills from TMDB, with TVmaze as a fallback.
- Automatic technical media analysis using MediaInfo.
- German and English interfaces, configurable metadata and artwork languages, light and dark themes, and optional fanart backgrounds.
- Poster thumbnails and five-star ratings, filtering, sorting, and bounded in-memory image caching.
- A copy-and-paste AI prompt dialog for creating short plot outlines.
- A new hand-drawn application icon.

## Choose a download

Choose the operating system and CPU architecture that match your computer.

- **Self-contained** archives include .NET 10. Extract the archive and start the application.
- Archives marked **framework-dependent** are smaller and require the matching **.NET 10 Runtime** to be installed first.
- Windows archives are ZIP files. Linux and macOS archives are TAR.GZ files.
- macOS packages contain an executable directory. Linux uses X11 or XWayland.

On Windows, start `VideoScrap2000.exe`. On Linux and macOS, start `VideoScrap2000` from the extracted directory.

The packages contain the native libraries for their target platform. Debug symbols, test assemblies, editor files, and other-platform runtimes are excluded.

## First start

Open Settings, select your movie and TV folders, then scan the library. Review search matches and save to write metadata and selected artwork into the media folders.

Release builds include the Fanart.tv project key. Users can optionally configure a personal Fanart.tv key.

For an existing Kodi entry, refresh the film's information to import a changed NFO. A library scan discovers new entries.

Each archive includes third-party license notices. The accompanying SHA-256 file verifies the downloaded archive. Package manifests record both download size and extracted file size.
