# VideoScrap 2000 0.3.0

The first release of VideoScrap 2000, a desktop metadata and artwork manager for movies and TV shows.

## Features

- Separate movie and TV-show libraries, including seasons and episodes.
- Metadata from TMDB and artwork from TMDB and Fanart.tv.
- Editable titles, plot outlines, descriptions, cast, ratings, certifications, collections, and provider IDs.
- NFO and artwork files saved alongside the videos, with backups of replaced files.
- TV artwork selection for the show or a specific season, including poster, fanart, banner, logo, clear art, landscape, and character art where available.
- Episode stills from TMDB, with TVmaze as a fallback.
- Automatic technical media analysis using MediaInfo.
- English and German interfaces with automatic system-language detection. Metadata and artwork also follow the system language by default; all three language preferences can be overridden separately. Preferred-language images are sorted first, while other languages remain available.
- Light, dark and system themes, with optional fanart backgrounds.
- Poster thumbnails and five-star ratings, filtering, sorting, and bounded in-memory image caching.
- A copy-and-paste AI prompt dialog for creating short plot outlines.
- A new hand-drawn application icon.
- An isolated screenshot demo with fictional movies, TV shows and original generated artwork. Start it from Settings or with `--demo`; the English movie example is prepared for showcasing the plot-outline AI prompt dialog.

## Choose a download

Choose the operating system and CPU architecture that match your computer.

- **Self-contained** archives include .NET 10. Extract the archive and start the application.
- Archives marked **framework-dependent** are smaller and require the matching **.NET 10 Runtime** to be installed first.
- Windows archives are ZIP files. Linux and macOS archives are TAR.GZ files.
- macOS packages contain an executable directory. Linux uses X11 or XWayland.
- Linux also requires the system's libcurl GnuTLS backend (`libcurl-gnutls.so.4`). The small libmms dependency is included in Linux packages.

On Windows, start `VideoScrap2000.exe`. On Linux and macOS, start `VideoScrap2000` from the extracted directory.

The packages contain the native libraries for their target platform. Debug symbols, test assemblies, editor files, and other-platform runtimes are excluded.

## First start

Open Settings, select your movie and TV folders, then scan the library. Review search matches and save to write metadata and selected artwork into the media folders.

Release builds include the Fanart.tv project key. Users can optionally configure a personal Fanart.tv key.

## Kodi support

VideoScrap 2000 saves Kodi-compatible XML NFOs and artwork beside your videos: movie NFOs normally match the video basename, shows use `tvshow.nfo`, and episodes use a matching NFO containing season and episode numbers. Saved artwork includes posters, fanart, show and season banners and posters, and episode stills where available. Additional artwork display depends on the Kodi skin and artwork settings. Movie NFOs also include available technical video, audio and subtitle details.

Add the media folders to Kodi with the correct Movies or TV shows content type. Choose **Local information only** if you want Kodi to use the metadata prepared by VideoScrap 2000. **Update library** discovers new movies and episodes. For changes to existing entries, open **Information → Refresh** and use the local information; a normal scan does not reread changed NFOs for existing entries.

Movie NFOs record the first-save date in `dateadded` and preserve it on later edits, separately from the release year. Existing NFOs and replaced artwork receive `.bak` backups.

VideoScrap 2000 works with local and mounted NAS folders. Kodi performs the import itself, including when it uses a shared MySQL/MariaDB library. VideoScrap 2000 does not write to Kodi's database or trigger remote library updates.

See [Kodi's NFO documentation](https://kodi.wiki/view/NFO_files) and [library update and refresh guide](https://kodi.wiki/view/Updating_or_removing_videos).
