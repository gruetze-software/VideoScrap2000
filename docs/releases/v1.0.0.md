# VideoScrap 2000 1.0.0

The first public release of VideoScrap 2000: a desktop metadata and artwork manager for movies and TV shows on Windows, Linux and macOS.

<!-- RELEASE_DOWNLOADS -->

## Highlights

- Updated 1.0 packages fix startup text rendering and migrate existing app data to `VideoScrap2000` automatically.
- Separate movie and TV-show libraries, with seasons, episodes and cast.
- Metadata from TMDB; artwork from TMDB and Fanart.tv; fallback episode images from TVmaze.
- Kodi-compatible NFOs and artwork saved beside the videos, with backups of replaced files.
- English/German interface and independent metadata and artwork languages following the client language by default.
- Poster thumbnails, star ratings, search, sorting and automatic technical media details.
- Light/dark themes, optional fanart backgrounds, and remembered window size and maximized state.
- An editable AI prompt dialog for short plot outlines: copy to ChatGPT or another service, then paste the result back. No AI API subscription is required by the app.
- A separate demo mode with fictional titles and original generated artwork.

## First start

Open **Settings**, select your movie and TV folders, then **Scan library**. Review metadata and artwork before choosing **Save changes**. Release packages include the Fanart.tv project key, so no per-client project-key setup is needed.

For Kodi, scan for new items. To import changed NFOs for an existing item, open **Information → Refresh** and use the local information. VideoScrap 2000 does not write directly to Kodi's database.

Read the [README](https://github.com/gruetze-software/VideoScrap2000#readme) and [Kodi guide](https://github.com/gruetze-software/VideoScrap2000/blob/v1.0.0/docs/kodi.md).

<details>
<summary>Starting the app and platform requirements</summary>

Extract the archive and run `VideoScrap2000.exe` on Windows or `VideoScrap2000` on Linux/macOS. macOS packages are executable folders, not notarized application bundles. Linux requires X11 or XWayland and `libcurl-gnutls.so.4`; libmms is bundled.

Packages contain only the selected platform's runtime libraries. Debug symbols, tests, screenshots and branding source files are excluded.

</details>
