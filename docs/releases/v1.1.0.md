# VideoScrap 2000 1.1.0

Stable release for Windows, Linux and macOS.

- Preserve the original metadata capture date when saving existing movies, including on Linux, macOS and mounted network shares. Dates already lost before this fix cannot be reconstructed automatically.
- Open temporary actor portraits through the desktop portal in Snap, matching the existing Flatpak handling. Native Windows and macOS file opening remains unchanged.
- Use the dedicated macOS icon in signed and Apple-notarized app bundles and DMG installers.

Includes movie and TV-show metadata management, Kodi-compatible NFO files, artwork downloads, English/German UI and configurable metadata and artwork languages.
