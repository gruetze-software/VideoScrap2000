# VideoScrap 2000 1.2.0

- Configure multiple movie and TV-show folders in Settings. Existing single-folder settings are carried forward. Sources can be added or removed independently; removing a source does not delete media files.
- Fix IMDb-ID conflicts when importing multiple editions of a movie in separate folders. Existing databases are migrated automatically, preserving movie IDs, relationships and cached images. Scan again to import editions previously rejected by the constraint.
- Remove actor portrait downloads from library scans so network requests no longer hold the database writer lock. Portraits load on demand and are cached for later use.
- Show scan progress with folder counts, errors and the last checked folder, followed by progress while preparing the library list. Cancellation remains available.
- Show folder names for matching movie titles and years to help distinguish editions.
- Index actor lookups and reuse directory listings during scanning.

Movie and TV-show scans process up to four folders in parallel across all configured sources. Multiple main videos in the same folder are not yet listed as separate editions; use a separate folder for each edition.
