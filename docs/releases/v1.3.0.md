# VideoScrap 2000 1.3.0

- Add scraper settings with personal TMDB read tokens, personal Fanart.tv keys and direct links to provider registration pages.
- Make TMDB artwork, Fanart.tv artwork and TVmaze episode-image fallback independently optional.
- Add optional TheTVDB v4 support for TV-show search, translated metadata, cast, episodes and available show/season artwork. Choose a default series provider or switch sources in the search dialog.
- Preserve provider-specific IDs and remember the selected show provider for episode updates after restarting.

TheTVDB requires separately approved project access and, for user-supported keys, a paid subscriber PIN. It is disabled by default. Movie metadata continues to use TMDB. [Scraper setup](https://github.com/gruetze-software/VideoScrap2000/blob/main/docs/scrapers.md).
