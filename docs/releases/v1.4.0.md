# VideoScrap 2000 1.4.0

- Simplify scraper settings to provider switches, the default series source and provider links. No API keys or PINs need to be entered.
- Make TMDB artwork, Fanart.tv artwork and TVmaze episode-image fallback independently optional.
- Add optional TheTVDB v4 support for TV-show search, translated metadata, cast, episodes and available show/season artwork. Choose a default series provider or switch sources in the search dialog.
- Preserve provider-specific IDs and remember the selected show provider for episode updates after restarting.
- Add a small remove button to movie, show and season artwork tiles. Removal is staged until Save changes, preserves a .bak backup and clears removed movie images from the cache.
- Show compact resolution, aspect ratio, codec and audio badges beside the title, with tooltips, Play and Open folder buttons for movies and episodes.
- Add structured media details and a Read again button to refresh technical information directly from the video file. Refreshed episode stream details are saved in Kodi-compatible NFOs.
- Apply the artwork optimization profile to actor portraits: Compact fits within 300 × 450 pixels and Balanced within 500 × 750, preserving originals and avoiding upscaling.
- Use VideoScrap 2000 as the native macOS application menu name.

Official builds include the TheTVDB project access; users do not need their own API key. The project access has been tested without a personal PIN. TheTVDB is an optional source and is disabled by default. Movie metadata continues to use TMDB. [Scraper setup](https://github.com/gruetze-software/VideoScrap2000/blob/main/docs/scrapers.md).
