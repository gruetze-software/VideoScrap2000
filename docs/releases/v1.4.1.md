# VideoScrap 2000 1.4.1

- **Artwork search:** Open the automatic search as soon as existing artwork has been identified. Manual and automatic searches share one dialog at a time.
- **Media details:** If a full MKV analysis times out, try reading track details from the beginning of the file.
- **Startup:** Optionally scan configured movie and TV folders after a two-second delay. Enable this under Settings → Sources.
- **macOS:** Use the application menu to open About or Settings, scan the library, or quit.
