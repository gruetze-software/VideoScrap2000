# VideoScrap 2000 1.4.2

- Check for new GitHub releases from the About dialog or by clicking the version number.
- Include 4K movie backgrounds from Fanart.tv in artwork searches.
- Optionally search TheTVDB for movie artwork by IMDb ID. The search dialog identifies the source of each result.
- Show movie ratings with one decimal place and the runtime in minutes on the same line in the library list.
- Replace cast portraits for movies and TV shows with a local JPEG, PNG, or WebP image, or choose a profile image from TMDB.
- Show matching people, known credits, and TMDB IDs when a name search returns multiple matches.
- Apply the artwork optimization profile to cast portraits. Compact and Balanced resize larger portraits to 500 pixels wide while preserving the aspect ratio and transparency. The cast preview shows the resulting resolution before saving.
